# 서동민 · 게임 기획 포트폴리오

공개 홈페이지: https://standupdongmin.github.io/dongmin-portfolio/

## 내용 수정

**`content.js`만 수정하면 됩니다.** 디자인을 담은 HTML·CSS나 화면 동작을 담은 `portfolio.js`는 수정할 필요가 없습니다.

- `site`: 상단 소개, 메뉴, 작업 태도, 섹션 제목, 하단 문구
- `profile`: 소개와 역량 버튼에 표시할 내용
- `works`: 작업별 제목, 개요, 담당 업무, 상세 설명, 버튼
- `games`: 게임 이름, 카드 제목, 상세 설명
- `ui`: 필터, 버튼 주변의 안내, 상세 항목 이름

예를 들어 첫 작업 제목은 `works`의 첫 항목에 있는 `"title": "무기 애니메이션"`에서 바꿉니다. `details`의 세 배열은 순서대로 **마주한 문제 → 대처와 해결 → 발전과 배운 점**입니다. 내가 어떤 어려움을 겪었는지, 무엇을 해서 해결했는지, 그 경험으로 무엇을 배웠는지가 이어지도록 작성합니다. 문단을 추가하려면 배열에 `"새 문단"`을 추가하세요.

일반 텍스트만 입력합니다. `<br>` 같은 HTML 태그는 넣지 않습니다. 줄을 구분할 수 있는 항목은 문자열 배열로 나뉘어 있습니다. 따옴표·쉼표·대괄호를 유지하세요. 문자열 안에 큰따옴표를 쓰려면 `\"`로 적습니다.

작업의 버튼은 `actions`에 두 개씩 있습니다. `label`은 버튼 문구, `title`은 팝업 제목, `detail`은 표시할 상세 배열 번호(0·1·2)입니다. `url`에 `https://`로 시작하는 공개 영상·자료 주소나 `assets/example.pdf` 같은 상대 경로를 넣으면 팝업에 자료 링크가 나타납니다. 로컬 컴퓨터의 `C:\...` 경로를 넣으면 다른 사람이 열 수 없습니다. 파일을 연결할 때는 해당 파일도 저장소에 올려야 합니다.

## 미리보기와 공개 반영

1. `content.js`를 저장합니다.
2. `index.html`을 브라우저에서 열거나 새로고침해 확인합니다. 별도 서버나 설치가 필요 없습니다.
3. GitHub Desktop에서 **dongmin-portfolio** 저장소를 선택합니다.
4. 변경 내용을 확인하고 요약을 입력한 뒤 **Commit to main**을 누릅니다.
5. **Push origin**을 누릅니다.
6. GitHub의 **Actions**에서 Pages 배포 완료를 확인하고 공개 홈페이지를 새로고침합니다.

**컴퓨터에서 파일을 저장하는 것만으로 공개 사이트가 바뀌지는 않습니다. 커밋·푸시와 Pages 배포가 완료되어야 방문자에게도 반영됩니다.** 오래된 화면이 보이면 `Ctrl+Shift+R`로 새로고침하세요.

## 배포 설정

GitHub Pages의 배포 소스는 `main` 브랜치의 `/ (root)`입니다. `index.html`, `content.js`, `portfolio.js`는 같은 폴더에 둡니다. `.nojekyll`을 유지합니다.

## 파일과 자료 기준

- `index.html`: 공개 홈페이지. 기존 CSS와 화면 구조를 유지합니다.
- `서동민.html`: 같은 콘텐츠를 읽는 한글 이름의 진입 파일입니다.
- `content.js`: 홈페이지에 표시할 내용입니다.
- `portfolio.js`: 콘텐츠를 표시하고 필터·상세 보기·팝업을 동작시킵니다.

내용은 제공받은 범용 AI 17쪽, 가디언 34쪽, 포트폴리오 개요 21쪽을 기준으로 정리했습니다. 작업별 `sources`에는 확인한 페이지를 적었습니다. 개요의 프로젝트 기간 표기가 다른 부분은 연도 수준으로 정리했습니다. 전투 시간 3~5분 등은 가디언 **제안의 목표·설정**입니다. 플레이 기록의 수치나 검증하지 않은 성과는 추가하지 않았습니다.

원본 PPTX는 수정하거나 이 공개 저장소에 업로드하지 않았습니다. 이미지와 그래픽은 기존 것을 유지합니다. 아직 별도 영상 주소나 다운로드 파일을 전달받지 않은 버튼은 실제 작업 설명을 표시하며, 나중에 `url`로 자료를 연결할 수 있습니다.
