# 서동민 · 게임 기획 포트폴리오

HTML, CSS, JavaScript로 구성한 정적 포트폴리오 홈페이지입니다.

## 홈페이지 수정 및 배포

1. `index.html`을 수정하고 브라우저에서 결과를 확인합니다.
2. GitHub Desktop에서 변경 내용을 커밋합니다.
3. **Push origin**을 누르면 GitHub Pages에 자동 반영됩니다.

GitHub Pages 배포 소스는 `main` 브랜치의 `/ (root)`입니다.
`.nojekyll`은 HTML 파일을 그대로 배포하기 위한 설정입니다.

## 파일

- `index.html`: 공개 홈페이지의 첫 화면
- `서동민.html`: 처음 전달받은 원본 HTML

## 자료 연결 전 확인 사항

현재 이력서·기획서·영상 버튼은 샘플 팝업입니다. 제출 전 실제 파일과 영상 주소를 연결하고, 상세 서술과 이미지도 최종 검토해야 합니다.
